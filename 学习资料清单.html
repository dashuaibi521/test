1使用规则：先读这页，再看后面

资料本身不值钱，"用对时间 + 配产出"才值钱。这份清单的每个条目都标了何时用、学到什么程度就收手。

三条规则

规则一：同一时间只开一条线

《研一详细执行计划》的技能顺序是单线程的：C++（9–10 月）→ Python（11 月）→ 深度学习（12 月）→ ROS2（1–2 月）→ 机器人学+MuJoCo（2–3 月）→ 复现（4–5 月）→ 控制理论（6 月）→ 写作（7 月）。清单里标了"何时用"——没到那个月份，不要碰那个资源。囤货式学习是研一最大的死法。

规则二：每个资源必须配产出

看课不产生任何东西。每个资源后面都写了"学完交出什么"——一个 GitHub 仓库、一张能放进组会 PPT 的图、一份复现报告。交不出来，就等于没学。

规则三：收藏 ≠ 学习

这份清单故意短。每个方向只留 1 个主推 + 1–2 个备选。网上那些"机器人学习资源大全 100 个"的帖子，全部不要看——它们唯一的作用就是让你焦虑。

9避坑指南：六种死法，一个都别踩

以下每一条，都是用无数人的一年时间换来的。

① 收藏癖：囤一堆"机器人学习资源大全"

这份清单已经够你用到研二。再看到"100 个必看资源"的帖子，直接关掉。焦虑的来源从来不是资源太少，而是没有产出。

② 同时开多条线：C++ 还没写完就开始看 RL

逐月表是单线程的。本月的资源下个月看，不会过期；这个月碰下个月的资源，两头都做不完。唯一例外：LeetCode 刷题和论文泛读是贯穿全年的碎片任务。

③ 把 B 站当剧追：三倍速看完，一行代码不敲

所有视频课的规则都是：看一集 → 敲一遍 → 合上视频复现一遍。敲不出来的章节回去重看。视频时长 ≠ 学习时长，产出物才是。

④ 复现选没有开源代码的论文

再说一遍：必须有开源代码（Papers with Code 里筛）。第一次复现就硬啃纯论文，你会在环境配置和调参上耗掉两个月，最后产出为零、信心归零。

⑤ 在宿舍学

深度块（周二/周五/周日）去图书馆或教研室。宿舍的床会在 20 分钟内打败你。这条不新，但值得再写一遍。

⑥ 把涉密内容传给云端 AI 或开源社区

组内数据、模型、论文初稿 = 绝不上传、绝不开源。你公开的东西只有三类：复现已公开论文的代码、自己做的开源仿真、课程项目。这条线越过一次，三年白干。

最后：这份清单怎么用（一句话版）

跟着逐月表走到哪个月，就打开哪一节的表，把标了"主推"的那一项做完、交出产出物——其他的全部当作不存在。
